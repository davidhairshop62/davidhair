# David Hair - 자동 서버 동기화 및 GitHub 자동 배포 안내서

## 1. 설정 완료된 내역
1. **자동 동기화 스크립트 및 Git Hook 구축**
   - `scripts/sync.sh`: 로컬 변경사항 스테이징, 커밋, GitHub 푸시 및 웹 서버(`/var/www/davidhair`) 자동 업데이트 수행.

2. **운영 서버 비밀번호 없는 SSH 자동 연동**

   - 터미널 단축 명령어: `ssh davidhair` 입력 시 바로 `/var/www/davidhair` 디렉토리로 이동 접속.

3. **AI 지원 자동화**
   - 대화 중 파일이 추가/수정될 때마다 AI가 자동으로 GitHub 및 운영 서버(`/var/www/davidhair`)에 반영합니다.

## 2. GitHub 비밀번호 없이 자동 푸시 1회성 설정 (SSH 전환)

1. [GitHub SSH Keys 설정 페이지](https://github.com/settings/keys) 접속 후 **New SSH key** 클릭
2. 아래 공개키(Public Key)를 복사하여 붙여넣고 저장:

ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAICPmtE4bj8ZjrIPQUPYO6EX5FXB+mVSJ7ZxpDGvqkx2f davidheonchang@MacBook-Pro.local

3. 터미널에서 원격 저장소 주소를 SSH로 변경:
   git remote set-url origin git@github.com:davidhairshop62/davidhair.git

## 3. 수동 동기화 실행 방법

터미널에서 아래 명령어를 실행하여 언제든지 서버와 GitHub에 일괄 업데이트할 수 있습니다:

# David Hair - 초고속 서버 동기화 및 수동 Git 관리 가이드

## 1. 변경 요약 (기존 문제 해결)
- **기존 문제**: 파일 하나 수정할 때마다 [로컬 Git 커밋 -> GitHub Push -> SSH 접속 -> 서버에서 GitHub Pull]의 3단계를 거치느라 10~20초 이상 걸리고 매우 느렸습니다.
- **개선 결과**:
  1. **초고속 서버 반영 (약 1초)**: Git과 GitHub를 거치지 않고, Mac에서 운영 서버(`/var/www/davidhair`)로 직접 변경된 파일만 `rsync` 전송합니다.
  2. **Git 수동 관리**: 자동 커밋/푸시를 전면 중단했습니다. Git은 하루에 1~2회(아침 다운로드, 저녁 업로드) 또는 원할 때만 수동으로 실행합니다.
  3. **확인 URL 항상 제공**: 파일 수정 작업이 끝나면 항상 `https://davidhair.atozhair.shop` 이동 링크를 제공합니다.

## 2. 주요 사용 명령어

### ① 서버 즉시 배포 (수정 파일 1초 반영)
터미널에서 아래 명령어 중 하나를 실행하면 변경된 파일만 1초 만에 서버에 배포됩니다.
(AI에게 수정을 요청할 때도 AI가 알아서 이 스크립트를 즉시 실행합니다.)
```bash
./scripts/deploy.sh
# 또는
npm run deploy
```

### ② 파일 저장 시 실시간 자동 업로드 (선택 사항)
터미널에 켜두면 Mac에서 파일을 저장할 때마다 자동으로 감지하여 0.5초 만에 서버로 전송합니다.
```bash
npm run watch
# 또는
./scripts/watch.sh
```
(종료하려면 터미널에서 Ctrl + C)

### ③ Git 작업 (하루 1~2회 또는 원할 때만 수동 실행)
- **GitHub에서 최신 코드 내려받기 (아침 출근 시 등)**:
  ```bash
  npm run git:pull
  # 또는
  ./scripts/git_pull.sh
  ```
- **GitHub로 오늘 작업 내용 백업/업로드 (퇴근 시 등)**:
  ```bash
  npm run git:push
  # 또는
  ./scripts/git_push.sh "오늘 작업 내용 요약"
  ```
